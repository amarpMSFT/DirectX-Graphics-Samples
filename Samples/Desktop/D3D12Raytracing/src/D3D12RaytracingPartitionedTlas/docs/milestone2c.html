D3D12 Raytracing — Partitioned TLAS sample (milestone 2c)

5832 balls in a 6×6×6 lattice of 216 partitions. Same scene, same shader, same BLAS; only the top-level structure differs.

partitioned (PTLAS, DXR2)

result size: 2,099,840 B
scratch size: 1,591,680 B
per-frame ops: 216 TRANSLATE_PARTITION
build_ms (EMA): ~0.123 ms

traditional (TLAS, DXR1)

result size: 1,760,128 B
scratch size: 640,512 B
per-frame ops: 5832 instance writes + full TLAS rebuild
build_ms (EMA): ~0.155 ms

What this milestone shows

Scene6×6×6 grid of partitions, 3×3×3 balls per partition (216 partitions, 5832 instances)
BLASshared single icosphere BLAS (DXR1 — cluster BLAS via CLAS lands in 2b/3)
PTLAS ops exercisedWRITE_INSTANCE (once), TRANSLATE_PARTITION (every frame, all 216 partitions)
AS-origin trackingper-frame as_origin = camera position; PTLAS instances stored partition-local; traditional bakes (world − as_origin) into every instance every frame
Identical outputboth modes produce pixel-identical renders
AdapterNVIDIA GeForce RTX 4090 (preview driver, DXR2/PTLAS=YES)
